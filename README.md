# 📊 My Market Calendar

한국·미국 시장 상황과 주요 일정을 한 화면에 모아 보는 개인용 대시보드입니다.

- 사이트: https://mammoth1230.github.io/market/
- 구조: **GitHub Pages**(화면) + **GitHub Actions**(10분마다 자료 수집) — 서버 없이 무료로 동작
- 투자 조언이 아니라 정보 제공용입니다.

---

## 1. 구현한 기능

### 맨 위 (모든 탭 공통)
| 기능 | 설명 |
|---|---|
| 📊 지금 시장은 | 미국·한국 증시, CNN 공포탐욕, 환율·유가 급변, 미국 10년물 경고, 엔캐리 경보, 다음 일정을 **정해 둔 규칙**으로 엮은 요약 문장 (AI 아님) |
| NEXT UP 카운트다운 | 휴장 안내를 뺀 다음 큰 일정까지 일·시·분·초, 관련 뉴스 3개 |

## 3. 손으로 관리하는 파일

| 파일 | 내용 | 언제 고치나 |
|---|---|---|
| `data/events.json` | 일정 목록 | 새 일정이 공식 발표될 때 |
| `data/guides.json` | 📖 읽는 법 해설 | 필요할 때 |
| `data/watchlist.json` | 관심 종목 목록 | 종목을 바꿀 때 |
| `data/rates-manual.json` | BIS에 아직 안 들어간 최근 금리 결정 | 중앙은행이 금리를 바꿨을 때 |
| `data/valuation-manual.json` | 선행 P/E (FactSet) | 매주 |

## 4. 파일 구조

```
index.html                    화면 (HTML + CSS + 자바스크립트)
scripts/collect.mjs           자료 수집 스크립트 (Node.js)
.github/workflows/collect.yml 수집 일정 (10분마다)
data/*.json                   수집된 자료와 손으로 관리하는 목록
```

## 5. 공식 출처로 옮기는 계획

원칙: **공식 기관·공식 API의 하루 마감 값**을 쓴다. 공식 출처가 없는 자료만 🟠로 표시하고 유지한다.

| 자료 | 옮길 공식 출처 | 필요한 것 |
|---|---|---|
| 코스피·코스닥 지수, 역대 최고가, VKOSPI | 한국거래소 KRX Open API | 인증키 + 서비스별 이용승인 |
| 한국 종목 가격·시총 | KRX Open API | 〃 |
| 한국 종목 매출·영업이익·PER·PBR | 전자공시 DART API | 인증키 |
| S&P500·나스닥 종가, 유가 | 미국 연준 FRED | 인증키 |
| 원/달러 (서울 시장 기준) | 한국은행 ECOS | 인증키 |
| S&P500 P/E·CAPE | S&P 공식 이익 자료, 실러 교수(예일대) 자료 | 없음 |
| 미국 종목 매출·영업이익 | 미국 증권거래위원회 SEC 공시 API | 없음 |
| **코스피 공포·탐욕 (새로 만듦)** | 공식 재료 7가지로 직접 계산 — 코스피의 125일 평균 대비 위치, 52주 신고가·신저가 종목 수, 상승·하락 종목 비율, 풋·콜옵션 거래 비율, VKOSPI, 주식·국채 수익률 차이(이상 KRX), 회사채·국고채 금리 차이(한국은행) | KRX·ECOS 인증키 |

**공식 출처가 없어 🟠로 유지하는 것**: 투자자별 순매수(연기금 포함 — 거래소 홈페이지 로그인으로만 공개), 미국 종목 주가, 외인소진율, CNN 공포·탐욕(CNN 자체 지수).

인증키는 GitHub 저장소의 **Settings → Secrets and variables → Actions**에 넣어서, 공개 저장소에서도 남에게 보이지 않게 한다.

KRX Open API 이용약관: 비상업적 이용만 가능, 화면에 "한국거래소 통계정보" 표시 필수, 받은 정보를 제3자에게 제공 금지 → 화면에 보여 줄 값만 저장한다.

## 6. 알려진 한계
