# 📊 My Market Calendar

한국·미국 시장 상황과 주요 일정을 한 화면에 모아 보는 개인용 대시보드입니다.

- 사이트: https://mammoth1230.github.io/market/
- 구조: **GitHub Pages**(화면) + **GitHub Actions**(1시간마다 자료 수집) — 서버 없이 무료로 동작
- 원칙: **공식 기관·공식 API의 자료**를 쓰고, 공식 출처가 없는 자료는 🟠로 표시한다. 숫자를 지어내지 않고, 날짜가 확정되지 않은 일정은 넣지 않거나 '확인 필요'로 표시한다.
- 투자 조언이 아니라 정보 제공용입니다.

## 1. 구현한 기능

### 맨 위 (모든 탭 공통)
| 기능 | 설명 |
|---|---|
| 📊 지금 시장은 | 미국·한국 증시, CNN 공포탐욕, 환율·유가 급변, 미국 10년물 경고, 엔캐리 경보, 다음 일정을 **정해 둔 규칙**으로 엮은 요약 문장 (AI 아님, 규칙은 4장) |

## 2. 자료 출처

✅ 공식 기관·공식 API / 🟡 공식 기관 자료지만 공개 API가 아닌 주소 / 🟠 비공식(민간 사이트의 내부 주소)

| 자료 | 받는 곳 | 공식 여부 | 수집 |
|---|---|---|---|
| 지수(S&P500·나스닥·코스피·코스닥)·유가·관심 종목 시세 | Yahoo Finance | 🟠 (인증키가 생기면 공식 출처로 — 6장) | 1시간 |
| 원/달러, 달러/엔·유로·파운드·위안 | 유럽중앙은행(ECB) 기준환율 | ✅ | 2시간 (하루 1번 고시) |
| VIX | Cboe 공식 일별 파일 | ✅ | 2시간 (하루 1번) |
| 미국 국채 10년물 | 미국 재무부 일별 금리 | ✅ | 2시간 (하루 1번) |
| 일본 국채 10년물 | 일본 재무성 금리표 | ✅ | 2시간 (하루 1번) |
| 비트코인·이더리움 | 업비트 공식 API | ✅ | 화면 1분 실시간, 기록 1시간 |
| 주요국 기준금리 | 국제결제은행(BIS) 통계 API + 캐나다은행 공식 발표(`rates-manual.json`) | ✅ | 3시간 |
| 금리 예측 확률 | 칼시(Kalshi) 공개 API | ✅ | 1시간 |
| 미국 CPI·PPI·고용 발표치 | 미국 노동통계국(BLS) API | ✅ | 6시간 |

| 일정 날짜 | 연준·BLS·ECB·일본은행·한국은행·엔비디아·MSCI 공식 일정 | ✅ (손으로 입력) | — |
| 뉴스 | Google 뉴스 공개 검색 RSS | ✅ | 1시간 |
| 신용잔고·투자자예탁금 | 금융투자협회 FreeSIS | 🟡 | 3시간 |
| S&P500 P/E·CAPE | multpl.com | 🟠 | 6시간 |
| 투자자별 순매수 | 네이버 증권 | 🟠 공식 API 없음 | 1시간 |
| CNN 공포·탐욕 | CNN 그래프용 주소 | 🟠 CNN 자체 지수, 공개 API 없음 | 1시간 |

## 4. 이 사이트가 정한 규칙 (공식 기준 아님)

화면에 ⚙ 표시로 구분합니다.

| 규칙 | 값 | 근거 |
|---|---|---|
| 요약 문장 '크게' / '소폭' | 두 지수 평균 ±1.5% 이상 / ±0.3% 미만 | 이 사이트가 정함 |
| 요약 문장에 유가·환율 언급 | 유가 ±3%, 환율 ±1% 이상 | 이 사이트가 정함 |
| 엔캐리 경보: 달러/엔 | 143 이하 주의, 141.7 이하 발동 | 2024년 8월 엔캐리 청산 때 저점 141.7 |
| 엔캐리 경보: VIX | 25 이상 주의, 30 이상 발동 | 2024년 8월 장중 최고 65.7, 시장에서 흔히 쓰는 구간 |
| 엔캐리 경보: 일본 국채 10년물 | 2.8% 주의, 3% 발동 | 시장에서 자주 언급되는 심리적 경계선 |
| 미국 국채 10년물 경고 | 4.6% 이상 | 시장에서 자주 언급되는 심리적 경계선 |
| 칼시 '거래 적음' | 누적 5천 계약 미만 | 이 사이트가 정함 |
| 지난 금리 결정 결과 | 회의 2일 전 금리 vs 8일 후 금리 (BIS) | ECB·BOJ는 결정 며칠 뒤부터 적용돼서 |
| CNN 공포·탐욕 단계 이름 | 0–24 극단적 공포 … 76–100 극단적 탐욕 | CNN 기준 |

## 6. 나중에 할 일 (보류 — 할지 고민 중)

공식 출처로 더 옮기려면 **무료 인증키**가 필요합니다. 받으면 GitHub 저장소 **Settings → Secrets and variables → Actions**에 넣어 공개 저장소에서도 남에게 보이지 않게 합니다.

| 할 일 | 공식 출처 | 필요한 것 |
|---|---|---|
| 코스피·코스닥 지수, 역대 최고가, VKOSPI | 한국거래소 KRX Open API (openapi.krx.co.kr) | 인증키 + 서비스별 이용승인(며칠) |
| 한국 종목 가격·시총 | KRX Open API | 〃 |
| 한국 종목 매출·영업이익·PER·PBR | 전자공시 DART API (opendart.fss.or.kr) | 인증키 |
| S&P500·나스닥 종가, 유가 | 미국 연준 FRED (fred.stlouisfed.org) | 인증키 |
| 원/달러 (서울 시장 기준) | 한국은행 ECOS (ecos.bok.or.kr) | 인증키 |
| **코스피 공포·탐욕 (새로 만들기)** | 공식 재료 7가지로 직접 계산 — 코스피의 125일 평균 대비 위치, 52주 신고가·신저가 종목 수, 상승·하락 종목 비율, 풋·콜옵션 거래 비율, VKOSPI, 주식·국채 수익률 차이(이상 KRX), 회사채·국고채 금리 차이(한국은행) | KRX·ECOS 인증키 |
| S&P500 P/E·CAPE | S&P 공식 이익 자료, 실러 교수(예일대) 자료 | 없음 (엑셀 파일 읽기 작업 필요) |
| 미국 종목 매출·영업이익 | 미국 증권거래위원회 SEC 공시 API | 없음 (연락처를 밝히는 머리말 필요) |

KRX Open API 이용약관: 비상업적 이용만 가능, 화면에 "한국거래소 통계정보" 표시 필수, 받은 정보를 제3자에게 제공 금지 → 화면에 보여 줄 값만 저장한다.

## 7. 파일 구조

```
index.html                    화면 (HTML + CSS + 자바스크립트)
scripts/collect.mjs           자료 수집 스크립트 (Node.js)
.github/workflows/collect.yml 수집 일정 (1시간마다, 매시 17분)
data/*.json                   수집된 자료와 손으로 관리하는 목록
data/state.json               하루 1번 바뀌는 공식 파일을 마지막으로 받은 시각
```

## 8. 알려진 한계

- 🟠 Yahoo 시세는 장중 약 15~20분 늦고, 수집이 1시간마다라 최대 1시간 더 늦을 수 있습니다.
- 공식 자료(환율·VIX·국채)는 하루 1번 마감 값입니다.
- GitHub Actions 예약 실행은 GitHub 사정에 따라 늦어지거나 건너뛸 수 있습니다.
- 🟠 표시 자료는 상대 사이트가 주소를 바꾸면 멈출 수 있습니다 (다른 자료에는 영향 없음). 멈추면 '갱신 현황' 표에 ⚠가 뜹니다.
